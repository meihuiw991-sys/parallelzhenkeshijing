# 启动与部署

## 1. 当前运行环境

- Python：3.11+
- Web 框架：FastAPI + Uvicorn
- 上传目录：`Pro`
- 后端目录：`Pro/Parallel-core`
- 本地虚拟环境：`Pro/Parallel-core/.venv`，首次启动自动创建

## 2. 推荐启动方式

```bash
cd Pro
./start.sh
```

首次启动前创建配置：

```bash
cp Parallel-core/.env.example Parallel-core/.env
```

填写实际 API Key 后再启动。

`start.sh` 会在当前项目目录创建虚拟环境、根据 `requirements.txt` 安装依赖并启动：

```bash
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8010
```

自定义端口：

```bash
PORT=8080 ./start.sh
```

## 3. 本机访问

```text
http://127.0.0.1:8010
```

`127.0.0.1` 和 `localhost` 通常被浏览器视为安全上下文，可直接申请摄像头和麦克风权限。

## 4. 局域网访问

查看 Mac 的 Wi-Fi 地址：

```bash
ipconfig getifaddr en0
```

假设结果为 `192.168.1.100`，同一局域网设备可尝试访问：

```text
http://192.168.1.100:8010
```

注意：

- `start.sh` 已绑定 `0.0.0.0`，服务端允许局域网连接。
- macOS 防火墙需要允许 Python/Uvicorn 接收传入连接。
- 浏览器通常不会允许普通 HTTP 局域网地址使用摄像头和麦克风。
- 若其他设备需要完整使用摄像头和语音功能，应配置 HTTPS。

## 5. 本地虚拟环境

`start.sh` 默认执行等价于以下初始化过程：

```bash
cd Pro/Parallel-core
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

需要开发和运行测试依赖时执行：

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
```

## 6. 上传和迁移

上传 `Pro` 目录时需要包含：

- `Parallel-core` 源码、Prompt、文档和 requirements 文件。
- `Parallel-panel/index.html`。
- 根目录 `start.sh`、`.gitignore` 和 `README.md`。

不要上传：

- `Parallel-core/.env`：包含真实密钥。
- `Parallel-core/.venv`：包含当前机器和系统相关文件，应在目标机器重新创建。
- `voice-test.wav`、缓存目录和 Python 字节码。

首次启动必须能够访问 Python 包源。依赖安装成功后，后续启动不再依赖目录外环境。

## 7. 停止服务

在运行 Uvicorn 的终端按：

```text
Ctrl+C
```

应用退出时会停止当前 Video Edit 和 Assistant 会话。
