# 配置说明

## 1. 配置加载规则

配置定义在 `app/config.py`，加载顺序为：

1. 项目根目录 `.env`。
2. 当前进程环境变量。

进程环境变量优先级高于 `.env`。

## 2. API Key 分工

| 配置 | 用途 |
|---|---|
| `MODEL_API_KEY` | JoyAI Video Edit |
| `MODEL_API_KEY_2` | Talker、Interaction、Voice |

Talker、Interaction 和 Voice 使用 `assistant_api_key`：优先读取 `MODEL_API_KEY_2`，未配置时回退到 `MODEL_API_KEY`。

不要把 `.env`、API Key 或带鉴权信息的日志提交到公开仓库。

## 3. Video Edit 配置

| 字段 | 说明 | 当前典型值 |
|---|---|---|
| `MODEL_WS_URL` | Video Edit WebSocket 地址 | 由模型文档提供 |
| `MODEL_HEALTH_URL` | 模型健康检查地址 | 由模型文档提供 |
| `MODEL_WIDTH` | 输入/输出宽度 | `1248` |
| `MODEL_HEIGHT` | 输入/输出高度 | `720` |
| `MODEL_FPS` | 目标帧率 | `24` |
| `MODEL_INPUT_CODEC` | 输入编码 | `mjpeg` |
| `MODEL_OUTPUT_CODEC` | 输出编码 | `mjpeg` |
| `MODEL_OUTPUT_QUALITY` | JPEG 输出质量 | `85` |
| `MODEL_GATE_ENABLED` | 模型 Gate 开关 | `false` |
| `MODEL_USE_PE` | Video Edit `use_pe` | `false` |

浏览器发送 Video Edit 启动请求时也明确传入 `use_pe: false`。

## 4. Talker 配置

```env
TALKER_WS_URL=ws://hubrouter.jd.com/v1/realtime?model=JoyAI-Talker
```

Talker 使用 WebSocket `realtime` 子协议，浏览器麦克风音频被转换为 PCM16/16kHz 后转发。

## 5. Interaction 配置

```env
INTERACTION_URL=https://hubrouter.jd.com/v1/chat/completions
INTERACTION_MODEL=JoyAI-VL-Interaction
INTERACTION_TIMEOUT_SECONDS=20
```

Interaction 使用最新一张原始摄像头 JPEG 帧。若第一次返回 `</silence>`，客户端会添加明确视觉指令并自动重试一次。

## 6. Voice 配置

未在 `.env` 配置时使用以下默认值：

```env
VOICE_WS_URL=ws://hubrouter.jd.com/v1/realtime?model=JoyAI-Voice
VOICE_NAME=default
VOICE_OUTPUT_SAMPLE_RATE=24000
VOICE_TIMEOUT_SECONDS=30
```

Voice 使用 `tts_text`，输出 PCM16、单声道、24kHz 音频。

## 7. 本地 Prompt

| 文件 | 用途 |
|---|---|
| `prompts/video-edit.txt` | Video Edit 渲染指令，每次开启穿越时重新读取 |
| `prompts/talker.txt` | Talker 角色、回复和工具策略，建立新会话时加载 |

修改 Talker Prompt 后需要刷新页面或重新建立 Assistant WebSocket 会话。

## 8. 应用配置

| 字段 | 说明 |
|---|---|
| `APP_HOST` | 配置模型中的默认 Host；当前 `start.sh` 明确覆盖为 `0.0.0.0` |
| `APP_PORT` | 配置模型中的默认端口；当前 `start.sh` 使用 `PORT` 或 `8010` |
| `LOG_LEVEL` | Python 日志级别，建议调试时使用 `INFO` |
