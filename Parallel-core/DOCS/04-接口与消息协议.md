# 接口与消息协议

## 1. HTTP 接口

### `GET /`

返回 `app/static/index.html`，并设置禁止缓存响应头。

### `GET /api/config/video-edit`

读取 `prompts/video-edit.txt`：

```json
{"prompt": "视频编辑 Prompt"}
```

### `GET /api/capabilities`

返回当前前端能力开关：

```json
{
  "video_edit": {"enabled": true},
  "voice_understanding": {"enabled": true},
  "visual_interaction": {"enabled": true}
}
```

### `GET /api/health`

返回本地服务状态、模型健康检查结果和当前会话数量。

## 2. Video Edit WebSocket

地址：

```text
/ws/render/{session_id}
```

### 浏览器到服务端

启动：

```json
{
  "type": "start_stream_edit",
  "prompt": "...",
  "options": {
    "output_quality": 85,
    "gate_enabled": false,
    "use_pe": false
  }
}
```

帧元数据后紧跟 JPEG 二进制消息：

```json
{
  "type": "input_frame",
  "seq": 1,
  "t_capture_ms": 1000,
  "mime_type": "image/jpeg"
}
```

停止：

```json
{"type": "tryon_stop"}
```

### 服务端到浏览器

主要事件：

- `system/connected`：本地 WebSocket 已连接。
- `render_status`：排队或启动状态。
- `virtual_tryon_stream`：模型已开始接收帧。
- `output_frame`：下一条二进制消息是渲染 JPEG。
- `model_event`：原始模型状态事件。
- `error`：请求或模型错误。
- `virtual_tryon_stop`：模型会话停止。

## 3. Assistant WebSocket

地址：

```text
/ws/assistant/{session_id}
```

### 浏览器到服务端

麦克风音频：

```json
{"type": "audio_chunk", "audio": "<base64-pcm16>"}
```

视觉快照：

```json
{"type": "vision_frame", "image": "<base64-jpeg>"}
```

心跳：

```json
{"type": "ping", "t": 123}
```

### 服务端到浏览器

| 事件 | 说明 |
|---|---|
| `assistant_status` | Assistant 连接状态 |
| `audio_input_ready` | 后端已收到麦克风音频 |
| `speech_started` / `speech_stopped` | Talker VAD 状态 |
| `user_transcript_delta` | 用户 ASR 增量文本 |
| `user_transcript_completed` | 用户完整 ASR 文本 |
| `assistant_route` | 本轮选择 Talker 或 Interaction |
| `assistant_text_delta` | Talker 回复增量文本 |
| `assistant_text_replace` | Interaction/Mock 最终文本 |
| `assistant_text_done` | 文本结束 |
| `assistant_audio_delta` | Base64 PCM16/24kHz 播放分片 |
| `vision_analysis` | 右下角视觉卡片状态与内容 |
| `assistant_tts_error` | 文本成功但 Voice 朗读失败 |
| `assistant_error` | Assistant 链路错误 |

`vision_analysis.state` 包含：

- `loading`：正在分析。
- `completed`：分析成功，读取 `result`。
- `skipped`：连续两次返回 silence，回退普通对话。
- `error`：Interaction 请求失败，读取 `message`。
