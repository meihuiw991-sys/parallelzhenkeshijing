# 开发指南

## 1. 目录结构

```text
Pro/
├── app/
│   ├── main.py                  # FastAPI 入口与 HTTP/WS 路由
│   ├── config.py                # .env 配置模型
│   ├── session.py               # Video Edit 本地会话
│   ├── model_client.py          # Video Edit 上游客户端
│   ├── assistant_session.py     # Talker/Interaction/Voice 编排
│   ├── talker_client.py         # Talker WebSocket 客户端
│   ├── interaction_client.py    # Interaction HTTP 客户端
│   ├── voice_client.py          # Voice TTS WebSocket 客户端
│   ├── visual_router.py         # 视觉意图确定性路由
│   ├── demo_mocks.py            # 演示固定问答
│   └── static/
│       ├── index.html           # 页面结构与 CSS
│       ├── camera-render.js     # 摄像头和 Video Edit
│       ├── assistant.js         # 麦克风、视觉快照和音频播放
│       └── audio-capture-worklet.js
├── prompts/
├── tests/
├── DOCS/
├── start.sh
└── pyproject.toml
```

## 2. 常见修改入口

### 修改页面 UI

编辑：

```text
app/static/index.html
```

该文件同时包含 HTML 和 CSS。

### 修改 Video Edit 行为

- 浏览器采集和显示：`app/static/camera-render.js`
- 本地协议和会话：`app/session.py`
- 上游模型连接：`app/model_client.py`
- Prompt：`prompts/video-edit.txt`

### 修改语音和视觉链路

- 浏览器麦克风/播放：`app/static/assistant.js`
- 服务端编排：`app/assistant_session.py`
- 路由判断：`app/visual_router.py`
- Interaction：`app/interaction_client.py`
- Voice TTS：`app/voice_client.py`

## 3. 前端缓存版本

修改 JavaScript 后，应同步更新 `app/static/index.html` 中的查询版本，例如：

```html
<script src="/static/assistant.js?v=20260815-10" defer></script>
```

这样可避免浏览器继续使用旧脚本。

## 4. 测试

先安装本项目测试依赖：

```bash
cd Pro/Parallel-core
.venv/bin/python -m pip install -r requirements-dev.txt
PYTHONPATH=. .venv/bin/pytest -q
```

前端 JavaScript 语法检查：

```bash
node --check app/static/assistant.js
node --check app/static/camera-render.js
```

Python 编译检查：

```bash
PYTHONPATH=. .venv/bin/python -m compileall -q app tests
```

## 5. 修改原则

- API Key 只保存在后端，不发送给浏览器。
- Interaction 必须分析原始摄像头画面。
- Video Edit 与 Interaction 的帧来源应保持隔离。
- 视觉结果优先原文展示和朗读，避免 Talker 二次改写。
- 新增路由规则时，需要为误判和正常路径同时添加测试。
- 不要在日志中打印 API Key 或原始音频内容。

## 6. 当前已知技术债

- 首次启动需要能够从 Python 包源下载依赖；后续运行使用项目内 `.venv`。
- `.venv` 不应随源码上传，应在目标系统通过 `start.sh` 重新创建。
- 根目录 `Pro/start.sh` 是上传部署的统一入口，`Parallel-core/start.sh` 是后端实际启动脚本。
- 前端集中在单个大型 `index.html` 中，后续可拆分 CSS 和组件。
- 局域网完整使用摄像头/麦克风需要 HTTPS。
- `StarletteDeprecationWarning` 来自测试依赖组合，不影响当前功能。
