# 日志与故障排查

## 1. 日志位置

### 浏览器

打开开发者工具 Console，过滤：

```text
ParallelVerse Voice
```

### 后端

运行 `./start.sh` 的终端。Assistant 日志前缀：

```text
[assistant:<session_id>]
```

## 2. 摄像头或麦克风无权限

典型浏览器错误：

```text
NotAllowedError: Permission denied by system
```

检查：

1. macOS“系统设置 → 隐私与安全性 → 摄像头/麦克风”。
2. 浏览器站点权限。
3. 使用 `localhost`、`127.0.0.1` 或 HTTPS。
4. 修改权限后完全退出并重新打开浏览器。

## 3. Talker WebSocket 403

典型后端日志：

```text
server rejected WebSocket connection: HTTP 403
```

检查：

- `MODEL_API_KEY_2` 是否正确。
- URL 是否包含 `?model=JoyAI-Talker`。
- Key 是否有 Talker 权限。
- `.env` 修改后是否重启 Uvicorn。

## 4. Interaction 卡片一闪而过

如果前端出现：

```text
vision_analysis state=loading
vision_analysis state=skipped
```

说明 Interaction 返回了 `</silence>`。当前代码会：

1. 使用明确视觉指令自动重试一次。
2. 第二次仍 silence 时保留右下角提示。
3. 回退到普通 Talker 对话。

正常重试日志：

```text
Interaction returned silence; retrying explicit visual request
Interaction response ... attempt=2
```

## 5. Interaction 返回错误

常见日志：

```text
visual analysis failed
```

检查：

- `INTERACTION_URL` 不应把模型名放在 URL Query 中。
- JSON Body 中应包含 `model: JoyAI-VL-Interaction`。
- 使用 `MODEL_API_KEY_2`。
- 是否已经收到视觉帧：`vision frame accepted`。

## 6. 视觉结果有文本但没有声音

确认后端顺序：

```text
connecting to Voice
Voice event type=session.created
Voice audio chunk received count=1
Voice synthesis completed
```

如果出现 `assistant_tts_error`：

- Voice URL 应包含 `?model=JoyAI-Voice`。
- 使用 `MODEL_API_KEY_2`。
- 请求类型应为 `tts_text`。
- 浏览器输出 `AudioContext` 需要用户交互后才能恢复。

可独立测试 Voice：

```bash
cd Pro/Parallel-core
.venv/bin/python test_voice.py
```

成功后会生成 `voice-test.wav`。

## 7. Interaction 分析了错误画面

浏览器日志应显示：

```text
已上传视觉快照 {source: "camera"}
```

当前 Interaction 固定分析 `cameraVideo`，不应出现 `source: "rendered"`。

## 8. 后台任务无响应

检查：

```text
assistant route task failed
```

该日志会包含视觉路由或 Mock 后台任务的完整异常堆栈。

## 9. 前端代码修改不生效

1. 确认编辑的是 `Pro/Parallel-core/app/static`。
2. 更新 `index.html` 中对应脚本的 `?v=` 版本。
3. 强制刷新浏览器。
4. 确认当前 Uvicorn 工作目录为 `Pro/Parallel-core`。
